# Сайт Павла Толокнова

Статический сайт без сборки и зависимостей. Основной текст и контакты доступны без JavaScript. Скрипт нужен только для необязательной галереи.

## Локальный просмотр

Из папки `site/`:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:4173/`. Можно открыть и `index.html` напрямую. Если сервер уже запущен для просмотра, повторно запускать его не нужно.

## Что редактировать

- Тексты и контакты — `index.html`. Контакты также указаны в JSON-LD в начале файла; при замене обновить оба места.
- Оформление — `styles.css`.
- Цвета, размеры и правила композиции — `DESIGN.md`. Все значения типографики определены в `:root` файла `styles.css`.
- Портрет — `assets/portrait.jpg`. Исходник `../profile photo.png` сохранён. Для новой фотографии подготовить JPEG примерно 672 × 840 px, сохранив оригинал отдельно. При изменении пропорций обновить размеры в HTML и `og:image:width/height`.
- Резюме — PDF на сайт не выкладывается (`assets/*.pdf` в `.gitignore`).

## Добавить рабочие фотографии

Положить снимки в `assets/` и заполнить список в `photos.js`:

```js
const photos = [
  {
    src: "assets/workshop.jpg",
    alt: "Павел Толокнов обсуждает производственную задачу с командой",
    caption: "Обсуждение работы участка",
  },
];
```

Для каждого снимка нужны `src`, `alt`, `caption`. Использовать пути относительно `index.html`. Подписи должны соответствовать реальному снимку. Изображение открывается по ссылке в исходном размере; `src` указывает на оригинал. Галерея адаптируется к ширине страницы. Пустой список `[]` полностью скрывает раздел. При отключённом JavaScript галерея скрыта, остальная страница работает.

Рабочих фотографий пока нет. Изображения из `../videos/papa-career-search/` — сгенерированные сцены для видеопроекта, не документальные фотографии. В сайт они не включены.

## Проверки

```sh
node --test tests/gallery.test.cjs
```

Тест проверяет пустой список, одну фотографию и несколько фотографий, подписи, alt и ссылки на оригиналы. Перед обновлением просмотреть страницу на 375, 768 и 1440 px, пройти ссылки клавишей Tab, проверить телефон, email и MAX. Во время локальной проверки не требуется совершать звонок или отправлять сообщение.

Проверка текущей тёмной версии: тесты галереи — 3/3. В отдельном тестовом Chromium проверены ширины 375/768/1440 px: переполнения нет, все числа KPI имеют одинаковый размер, навигация клавиатурой и переход к контактам работают. PDF скачивается через браузер и побайтно совпадает с оригиналом. Проверены основное содержание без JavaScript и галерея 0/1/3, ошибки загрузки ресурсов и JavaScript отсутствуют. Скриншоты просмотрены на всех трёх ширинах. Контраст текста с соответствующим фоном — не ниже 5,39:1. Скриншоты, локальный сценарий проверки и отчёт находятся в `.preview/` и исключены из Git. Отдельное открытие MAX, отправка писем, звонки, публикация и индексация не проверялись.

После редактирования текста проведена проверка `unslop`: убраны общие вводные и повторяющийся блок профессионального пути; численные утверждения сохранены по исходному резюме. Пройдены проверки U1–U8: артефактов чата, новых неподтверждённых фактов, обязательных одинаковых троек и отрицательных противопоставлений нет; подписи чисел связаны с источником, названия компаний единообразны.

Последняя проверка также охватывает увеличенный портрет на трёх ширинах и последовательный доступ клавишей Tab ко всем трём контактным кнопкам. Их ссылки сохранили исходные адреса email, телефона и MAX.

## Публикация после явного разрешения

Папка `site/` — отдельный Git-репозиторий, начальная ветка `site`. Коммитов и удалённого репозитория пока нет. Исходные документы и видеопроект находятся за его пределами.

План: публичный репозиторий `DonnyHipp/pavel-toloknov`, GitHub Pages → **Deploy from a branch** → ветка **site**, папка **/(root)**. Файл `.nojekyll` позволяет отдавать статические файлы напрямую. В `main` и `master` не пушить; коммит и push выполнять только по отдельному явному разрешению.

Опубликовано: `https://donnyhipp.github.io/pavel-toloknov/`. Пункты 1–3 выполнены; при переезде на `ptoloknov.ru` заменить адрес в `canonical`, `og:url`, `og:image`, JSON-LD и `sitemap.xml`:

1. Добавить в `<head>` `link rel="canonical"` и `meta property="og:url"` с подтверждённым URL.
2. Заменить `og:image` и JSON-LD `image` на абсолютный HTTPS-адрес портрета; добавить JSON-LD `url` для страницы и человека.
3. Добавить `sitemap.xml` с единственным `<loc>` — подтверждённым URL страницы. Не использовать локальный адрес.
4. Проверить загрузку CSS, изображений и скриптов по пути `/pavel-toloknov/`, открыть MAX.
5. Проверить JSON-LD в Rich Results Test. Наличие метаданных не гарантирует индексацию или специальное отображение в поиске.

Правки в HTML, CSS и списке фотографий не требуют сборки: обновляются те же файлы в ветке `site` после разрешения на push.
